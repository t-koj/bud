# テスト方針
* コードを追加・編集した場合は、対応するテストを作成・更新する
* テストは tests/ 以下に作成するか、各実装ファイル中に記載する。
* 本プロジェクトは `[[bin]] harness = false`（`Cargo.toml`）かつ
  `xtensa-esp32-espidf` ターゲット専用のため、`cargo test` は `#[cfg(test)]` の
  コンパイルは通るが、既定のテストランナー（`espflash flash --monitor`）が
  実機への書き込みを試みるため、実機が無い環境ではテストの実行（アサーション検証）
  はできない。ハードウェアに依存しない純粋なロジック（バイト列パース、
  レジスタ番号計算など）は`#[cfg(test)]`として書き、コンパイルが通ることと
  ロジックの整合性をコードレビューで担保する。
