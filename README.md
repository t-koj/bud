# bud

LEGO に ATOM Matrix（ESP32-Pico）と ATOMIC Motionベースを組み込み、
PS4 (DualShock 4) コントローラーで操作するロボット。

## 使い方

1. 本体の電源を入れる。
2. PS4コントローラーを接続する。
   * すでにペアリング済みのコントローラーは、PS(HOME)ボタンを押すと接続する。
   * 初めて使うコントローラーは、SHARE+PSボタンを同時に長押しして
     ペアリングモード（LEDが高速点滅）にすると、本体が自動で見つけて接続・登録する。
3. 接続すると、コントローラーの入力で操作できるようになる。
   * 左スティック上下: サーボ(S1)の角度を操作する
   * 左スティック左右: サーボ(S2)の角度を操作する
   * 右スティック上下: サーボ(S3)の角度を操作する
   * 右スティック左右: サーボ(S4)の角度を操作する

詳しい仕様は [docs/spec.md](docs/spec.md) を参照。
